
GLACIAL LAKE DETECTION — TECHNICAL & EVALUATION REPORT
GLOFeagles 2026 Challenge
=======================================================

1. METHODOLOGY
──────────────
Architecture : SegFormer (nvidia/mit-b2)
Task         : Binary Semantic Segmentation
Classes      : 0 = Background, 1 = Glacial Lake
Input size   : 512×512 RGB

Training was conducted in two phases using a semi-supervised
pseudo-labeling strategy to maximize use of the limited
labeled data (60 images).

PHASE 1 — Supervised Baseline (60 labeled images)
  Split       : 48 train / 12 val (80/20)
  Optimizer   : AdamW (lr=6e-5, weight_decay=0.01)
  Scheduler   : CosineAnnealingLR (T_max=50)
  Augmentation: Horizontal flip, Vertical flip
  Epochs      : 50 (best at epoch 16)
  Best Dice   : 0.6611  |  IoU: 0.5090

PHASE 2 — Pseudo-labeling + Fine-tuning (447 images)
  Step 1: Model predicted all 515 unlabeled images
  Step 2: Confidence filtering
          - Threshold : avg pixel confidence > 0.85
          - Coverage  : 0.1% < lake% < 60%
          - Accepted  : 387/515 pseudo-labels
  Step 3: Fine-tuned FROM Phase 1 checkpoint
          - Combined  : 60 real + 387 pseudo = 447 images
          - Split     : 388 train / 59 val
          - Optimizer : AdamW (lr=2e-5) — lower for fine-tuning
          - Scheduler : OneCycleLR (10% warmup)
          - Early stop: patience=8
          - Best Dice : 0.9348  |  IoU: 0.8790

KEY DESIGN CHOICES JUSTIFIED:
a) SegFormer over UNet/DeepLab
   Hierarchical transformer captures both local texture and
   global context — critical for lakes varying from small dark
   ponds to large cyan/turbid bodies across 575 diverse images.

b) Pseudo-labeling over pure supervised
   Only 60 labeled images — insufficient to generalize across
   6 interference classes. Pseudo-labeling expanded dataset
   7.4× without additional manual annotation effort.

c) Fine-tuning from checkpoint (not from scratch)
   Preserves learned lake features from Phase 1.
   Lower LR (2e-5 vs 6e-5) prevents catastrophic forgetting.

d) Confidence threshold 0.85
   Ensures only high-quality pseudo-masks enter training.
   Average confidence was 0.989 across accepted pseudo-labels.

e) Turbid lake boost (REJECTED)
   Rule-based RGB detection for yellow/olive lakes caused
   false positives on red rock and snow. SegFormer-only
   predictions proved cleaner and more reliable.

3. EVALUATION METRICS (on 60 labeled images)
─────────────────────────────────────────────
  mIoU        : 0.7884
  F1          : 0.8817
  Precision   : 0.9042
  Recall      : 0.8603
  Accuracy    : 0.9938
  Kappa       : 0.8785
  Dice        : 0.8817

NOTE ON ACCURACY:
Pixel-level accuracy (0.9938) is high due to class imbalance —
glacial lakes occupy <5% of pixels on average. We therefore
prioritize mIoU (0.7884) and F1 (0.8817) as primary metrics,
which are robust to class imbalance. Cohen's Kappa (0.8785)
is also highlighted as it corrects for chance agreement under
imbalanced distributions — values >0.80 indicate near-perfect
agreement beyond chance.

NOTE ON EVALUATION SCOPE:
Ground truth masks are available for 60 of the 575 competition
images. All metrics above are computed on these 60 images.
Predictions for all 575 images are provided in segmentation_masks/.

5. REPRODUCIBILITY
───────────────────
Direct evaluation without retraining:

  from transformers import SegformerForSemanticSegmentation
  model = SegformerForSemanticSegmentation.from_pretrained(
      "checkpoints/segformer_v2"
  )

Or use inference.py:
  python inference.py --input_dir /path/to/images \
                      --output_dir /path/to/output \
                      --checkpoint checkpoints/segformer_v2
